# Portal de Evidencias

Aplicación web responsiva hecha con HTML, CSS y JavaScript. Implementa:
- Registro e inicio de sesión local.
- Perfil del estudiante.
- Formación académica.
- Formación extracurricular.
- Proyectos.
- Evidencias.
- Alta, consulta, edición, eliminación y búsqueda de registros.
- Persistencia en localStorage del navegador.

## Ejecutar en Visual Studio Code
1. Descomprime `portal_evidencias.zip`.
2. Abre la carpeta `portal_evidencias` en Visual Studio Code.
3. Instala la extensión **Live Server**.
4. Abre `index.html` y pulsa **Go Live**.
5. Registra una cuenta y entra.

## Importante
Esta es una versión funcional de demostración que guarda los datos en el navegador mediante localStorage. No tiene servidor ni autenticación segura; no uses datos personales reales o sensibles. Los registros no se sincronizan entre dispositivos y pueden perderse si se borran los datos del navegador. Para producción se requiere backend, base de datos, autenticación segura y almacenamiento de archivos.
